# Day 2 — Python for Data Science (8 hours)


## Learning Objectives
- Use Python's core data types and control flow fluently.
- Write clean, reusable functions with clear parameters.
- Write list comprehensions and read basic object-oriented code.

## Topics Covered

**2.1 Data Types** — `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, `set`, including common methods for each sequence/mapping type.

**2.2 Control Flow** — `if`/`elif`/`else` branching, `for` and `while` loops, `break`/`continue`.

**2.3 Functions** — parameters vs. arguments, default parameter values, `return`, docstrings, keyword arguments.

**2.4 List Comprehensions** — basic syntax, filtering with `if`, conditional `if`/`else` expressions, nested loops, dict and set comprehension variants.

**2.5 OOP Basics** — classes, `__init__`, `self`, attributes, methods, creating multiple independent instances.

## Hands-On Lab
1. Function that returns mean, min, and max of a list as a dictionary.
2. Rewrite a for-loop that filters even numbers as a list comprehension.
3. Define a class representing a data record with at least two attributes and one method.
4. Markdown explanation for each cell.
